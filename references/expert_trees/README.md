# Expert reference evidence

Each `machine_readable/expN.json` is the canonical expert evaluator and records
the original evaluator file, checksum, verbatim author/date, role, and a separate
canonicalization role/date. DOT, SVG, and PDF forms are generated by
`scripts/build_expert_references.py`; `INDEX.csv` records the exact commands.

Trace witnesses, extrema, and representative mutations are available only for
exp2, exp14, exp16, exp18, exp20, exp33, and exp34. For the other 27 experiments,
only the final expert satisfied region survived. Their JSON status is
`unavailable_final_tree_only` and states what must be reconstructed: the expert's
annotated trace/plot, threshold crossings, and independent derivation notes.
Those missing materials are not inferred or fabricated.

The original exp33/exp34 `AccuracyRR.py` cases are retained byte-for-byte. Their
axis order/units conflict with the authoritative registry. The canonical trees
therefore use trace-derived RR semantics, while both original boxes and the
correction rationale remain in the JSON provenance.
