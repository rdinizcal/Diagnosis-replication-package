# Derived results

Disposable outputs from `./reproduce-analysis`. Delete and regenerate them at
any time. They include seed-level RQ1 confusion matrices, deterministic grid
specifications/checksums, all per-seed tool trees, modal selections, RQ2 per-run
and aggregate statistics, paper LaTeX rows, SVG/PDF trees, and manuscript-value
checks. They are never inputs to a rerun and paper-facing CSVs are compared
against `expected/`.
