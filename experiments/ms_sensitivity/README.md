# MS sensitivity status

The old exp2/exp4 MS=100 versus MS=1000 numbers were generated by a superseded
campaign, and neither its effective configurations nor raw outputs survive. The
manuscript already marks those numbers as deleted.

`materialize.py` creates 40 controlled configurations from the same frozen tool
snapshot as the main evaluation. Only `ga.target_sats` changes; count mode means
that both satisfied and violated pools must reach MS. These configs have not
been executed. `generate_table.py` consequently emits an explicit evidence
status table with blank timing/precision/recall fields. It refuses to aggregate
a partial campaign. No historical values are relabeled as current results.
